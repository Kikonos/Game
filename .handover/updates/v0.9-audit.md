# v0.9 fix round 4 — plan from the independent audit

## Summary

1. Yes, there are release blockers: the Y.1 gate re-check (`restFailed`) ignores gate holds, and when it does fire the flight is invisible to the ladder/OpsStrip/pause badge/map and every replacement fix in Crew Control is refused, so the agreed "fresh crew / delay / sub-charter" gate decision cannot be played.
2. The global problems list still hands out a crew-SHORTAGE card for an out-of-hours flight, so item T ("own alert type everywhere") is not met on the Inbox, DutyModal, BlockSheet and Why surfaces.
3. Sound: Crew Control previews leak cues/pauses from state copies into the live game (double/triple chimes for delays the player only looked at), and "cash below zero" never sounds the triple on the day it happens. Both break the player's fixed sound meanings (S).
4. Heads/achievements: "A year without an overdue check" can never be earned by a clean operator, and the Fleet & positioning planner promises positioning/slip plans it never builds (item 5, text in Team view claims it).
5. Roster rules: `morningFree: 0` (design says 360) lets the planner put a 05:00 standby right after every off block, which an ex-FA will spot at once; the rest of the roster items are medium/low and must wait for round 3 to merge.
